# paper_discuss — 循环精化阶段（Phase 8）

## Phase 8: 循环精化（结合前轮状态）

- 基于 Round N 的 findings 精化 query → 回到 Phase 2
- **关键：新轮搜索/定位时，结合前几轮对比和讨论的论文**：
  - 排除已下载/已讨论的论文（`exclude` 参数）
  - 从 findings 提取新关键词（如"自条件化"、"扩散策略"等子方向）
  - 对比后发现的缺口方向 → 定向搜索补充论文
  - **引用追踪发现的 new_papers → 加入本轮定位候选**
- **关键：深入时覆盖全部已下载论文**：
  - 每次 `search_tex` 默认检索 `docs/arxiv/` 下全部论文
  - 用 `exclude=[已讨论的]` 聚焦新论文
  - 用 `include=[目标论文]` 精确对比
- 2~3 轮后输出最终综合结果（含各轮对比结论 + 引用追踪发现）
