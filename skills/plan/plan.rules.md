## 规则 #11 — Python 语法检查
任何新建或修改 `.py` 文件的步骤，执行后必须先调用语法检查工具验证：
```
python skills/check/check_syntax.py <文件路径>
```
- 语法 ❌ → 立即修复，修复后再次检查，直到通过
- 批量场景（3+ 文件）使用 `--summary` 模式只输出汇总
