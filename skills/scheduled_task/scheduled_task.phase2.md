## Phase 2 — 命令执行

> 📂 **加载时机**：进入 Phase 2 时加载
> **用途**：条件已满足，执行用户在 Phase 0 中指定的命令

---

条件已满足！执行用户在 Phase 0 中指定的操作。

### 执行步骤

1. **理解意图** — 回顾 Phase 0 中用户指定的命令
2. **分析当前上下文** — 结合当前系统状态或会话历史
3. **执行操作** — 使用合适的工具/技能完成用户命令
4. **输出结果** — 向用户报告执行结果

### 示例

| 用户命令 | LLM 执行方式 |
|---------|-------------|
| "执行备份脚本 backup.sh" | 通过 bash 运行脚本 |
| "发送通知到钉钉群" | 使用 webhook/skill 发送 |
| "重启 nginx 服务" | 通过 bash 执行系统命令 |
| "打印系统状态报告" | 收集信息后格式化输出 |

> 使用哪个工具/技能取决于用户命令的类型，`scheduled_task` 不限定执行方式。
