# 09 · 命令系统

简体中文 | [English](09-commands.md)

---

在 REPL 和 Web 中，普通文本会交给 Agent，`/` 开头的内容由 XKAgent 处理，`!` 开头的内容则直接交给宿主机 shell。两种界面共用 slash 命令注册表，主要差异在交互确认、会话多选和退出方式。随时可以输入 `/help` 查看内置帮助。

## 先分清三种历史操作

`/clear`、`/drop` 和 `/compact` 看起来相近，实际用途不同：

- `/clear` 删除当前 session 的消息，并重置 token 统计
- `/drop` 清空 Agent 当前使用的上下文，但在数据库中保留旧消息并写入边界标记
- `/compact` 让模型总结当前对话，保留数据库旧消息，以总结作为后续上下文，并把总结写入 `.xkagent/docs/<session>/`

如果只是上下文太长，应使用 `/compact`；想从空上下文继续但仍保留数据库记录，可使用 `/drop`；只有确认不再需要当前会话消息时才使用 `/clear`。

## 查看运行状态

- `/help`：显示命令帮助
- `/logfile`：显示本次进程的日志路径和末尾 60 行
- `/cmds [n]`：查看当前 session 最近的 slash 与 `!` 命令，默认 50 条
- `/sessions`：列出运行中和未运行的会话
- `/session`：显示当前 session、模型、模式和 token 统计

`/cmds` 是命令操作记录，不是逐文件修改历史，也不能代替 Git 或备份。

## 管理会话

```text
/session add experiment
/session fork experiment-copy
/session experiment
```

- `/session <name>`：切换会话；精确名称优先，也支持唯一的模糊匹配
- `/session add <name> [--no-switch]`：新建会话，默认创建后切换
- `/session fork <name>`：复制当前会话及其数据库状态
- `/session rename <name>`：重命名当前会话
- `/session remove <name>`：删除非当前会话
- `/session stop <name>`：停止该会话的 Agent，保留数据
- `/session sync [name]`：执行 SQLite WAL checkpoint

REPL 可以在删除、重命名或多项模糊匹配时交互确认；Web 无法终端多选，会返回候选名称。会话被其他进程占用时会进入观察者只读状态，聊天和写类命令会被拒绝。

## 模型与执行模式

- `/model`：显示当前 provider、模型、reasoning effort 和可用模型
- `/model <name>`：切换模型
- `/model @<provider>`：切换 provider
- `/model <name>:<effort>`：切换模型，并为当前会话临时覆盖 reasoning effort
- `/model test [name]`：测试全部已配置模型或指定模型
- `/plan`：切换到只读规划模式
- `/build`：切换到受限可写模式
- `/build-unsafe`：切换到接近宿主 Python 的高风险模式
- `/mode`：按 `plan → build → build-unsafe → plan` 循环切换

模式约束的是 Agent 的 `pythonrt` 执行路径，不会限制后文的 `!shell` 直通通道。

## 技能

- `/skills`、`/showskills`：列出可加载技能
- `/validate [names]`：校验全部或指定技能
- `/skill <name>`：读取技能并加入当前 Agent 的活动技能列表
- `/turnonskill`、`/skillson`：开启自动技能选择
- `/turnoffskill`、`/skillsoff`：关闭自动技能选择

当前 `/skill` 不等同于“下一回合强制执行”；普通消息中的候选检索、自动选择和正文注入仍由回合流程处理。详见 [技能系统](07-技能系统.md)。

## 搜索与图片

- `/info`、`/info list`：查看全局、当前 session 和合并后的搜索范围
- `/info add [--global] <path> [scope]`：添加搜索路径
- `/info deny [--global] <path>`：按路径前缀排除目标
- `/info remove [--global] <path>`：移除一条配置
- `/info clear [--global]`：清空当前层配置
- `/updateembedding`、`/updateskillembedding`：全量重建向量索引
- `/image add <path>`：为当前 session 附加本地图片
- `/image list`：列出待发送图片
- `/image clear`：清空图片附件

图片单文件上限为 10 MB，路径保存在当前 session 中；图片注入下一条用户消息后会自动清空。向量索引默认不会自动增量更新，`/updateembedding` 还可能准备本地模型，执行时间取决于环境。

## 挂载路径

- `/mount <path> [ro|rw|ro/rw] [--force]`：为当前 session 动态挂载路径
- `/mount list`：查看默认、全局和动态挂载
- `/mount save`：把动态挂载追加到全局 `permission.txt`
- `/mount refresh`：重新读取 `permission.txt`
- `/unmount <path>`：移除当前 session 的动态挂载

动态挂载会保存在 session 数据库中，重启后恢复；`/mount save` 则用于转成全局配置。`plan` 下所有挂载都按只读处理。危险路径需要确认：REPL 会询问，Web 会要求显式重发 `--force`。挂载和沙箱都是降低误操作风险的软边界，不是安全容器。

## 压缩、重启与退出

- `/compact`：通过专用模型回合总结会话并重置后续上下文
- `/restart [overrides]`：停止当前 Agent 并重启进程，可覆盖 `--mode`、`-s`、`--port`、`--resume`、`--workdir` 等启动参数
- `/exit`：退出 REPL；在 Web 中关闭服务器

`/compact` 不在普通命令注册表中。前端会把它改写成专用消息，经流式模型回合生成总结；它不是一个立即完成的本地命令。总结失败或回合中断时，原历史保持不变。

## `!shell`：高权限直通

```text
!git status
!python -m pytest
```

`!` 后的文本由 REPL 或 Web 直接传给宿主机默认 shell。stdout、stderr 和退出码会展示，并记录到当前 session 的命令历史。这个通道不经过 Agent 工具调用，也不受 `plan`、`build` 或 `pythonrt` 沙箱约束。

只运行你完全理解的命令，不要粘贴来源不明的一行脚本、密钥或破坏性命令。Slash 命令发生异常时会转换成错误文本返回前端；`!shell` 则拥有宿主权限，风险边界完全不同。
